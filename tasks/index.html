⚠️ 请用本地 HTTP 打开 —— file:// 下无法评测
浏览器把每个 file:// 本地文件当作独立 origin，本页读不到游戏 iframe 里的 window.BENCH（控制台会报 Blocked a frame with origin "null"）。 也就是说：游戏能玩，但成绩一律不会被记录。为了不让你白玩一整局，这里直接拦住了。
① 在本目录的终端里执行：
cd RealtimeGameForHuman && ./serve.sh
② 然后用浏览器访问（端口以脚本打印的为准）：
http://127.0.0.1:8765/
没有 python3 时，用任意静态服务器指向 RealtimeGameForHuman/ 目录即可； 详见同目录 README.md 的「怎么打开」一节。

RealtimeGUI Benchmark · 人类评测

共 69 个实时 HTML 游戏，覆盖四类任务（视频补丁 / anticipation / 组合补丁 / 无补丁）。
请依次游玩每个游戏，系统会自动记录每个游戏的用时、成功与否、第几次成功，并在每个游戏结束后请你自评难度与趣味性。

发现未完成的评测
—
· 评测可中断：进度会自动保存在本机浏览器里，关掉页面后再打开可继续。
· 每个游戏最多 3 次机会；中途可「跳过本游戏」（跳过不计入成功率）或「暂停」。
· 记录的时长是墙钟时间，含回合之间的自评与点击操作停顿。
