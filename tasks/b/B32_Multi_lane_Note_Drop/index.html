Multi-Lane Rhythm 多轨道节奏
In this rhythm game, 4 notes are scattered randomly across 4 lanes (keys D F J K from left to right). Before they fall, the notes stay still and each note shows the time it reaches the hit line — the first note reaches the line 1.5s after Start, then one every 0.8 second. Press the matching lane key when a note hits the line (±150ms). Wrong key or bad timing breaks the rhythm.
在这款音游里，4 个音符随机分散在 4 条轨道上（从左到右对应 D F J K）。下落前音符会静止显示，且每个音符标出它到达判定线的时刻——第一个音符在 Start 后 1.5 秒到达判定线，之后每隔 0.8 秒一个。当音符到达判定线时按对应轨道键（±150 毫秒）。按错键或时机不对都会断节奏。
