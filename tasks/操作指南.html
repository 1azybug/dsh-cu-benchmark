实时小游戏评测 · 操作指南

一次连续体验 69 个小游戏，用于收集真实的人类操作数据。全程约 60–90 分钟，可随时暂停、分几次做完。

一句话流程：解压 → 双击启动脚本 → 浏览器自动打开 → 输入姓名 → 依次玩 → 最后「导出 CSV」把文件发回。

一、开始之前（1 分钟）

  1. 把压缩包完整解压到一个文件夹（不要直接在压缩包里双击运行）。路径里带中文没关系。
  2. 用 Chrome 或 Edge 最新版（其它浏览器也能玩，但这两个最稳）。
  3. 把中文输入法切成英文（Shift 或 Ctrl+空格）。
    原因：中文输入法会截获字母键和方向键去做选字，游戏会收不到你的按键——这不是游戏坏了。
  4. 关闭会抢占前台的程序：录屏、视频播放器、屏幕共享、弹窗提醒等。这类游戏有时间判定，窗口被切走或卡顿会影响成绩。

二、怎么打开（关键步骤）

Windows

双击 启动评测-Windows.bat。会弹出一个黑色命令行窗口（这个窗口不要关），浏览器会自动打开评测页； 如果没自动打开，手动访问窗口里显示的地址 http://localhost:8765/（端口号可能不同，以窗口里显示的为准）。

macOS / Linux

在终端里执行（首次可能需要右键 → 打开，或在终端里运行以绕过安全限制）：

cd 解压后的文件夹 && ./启动评测-macOS-Linux.sh

终端会打印访问地址并自动打开浏览器。终端窗口不要关。

⚠️ 不要直接双击 index.html（会被页面拦住，这是故意的）
浏览器把每个本地文件（file://）当作独立来源，页面读不到游戏里的成绩， 于是会出现一个红色全屏遮罩、写着「请用本地 HTTP 打开」。原因：如果放任你直接玩， 你可能认真玩完一整局，而成绩一条都不会被记录——那比进不去更糟。所以务必用上面的启动脚本。

三、怎么玩

环节你要做什么
每局开始前页面会出现一张提示卡，写清这款游戏的开始方式、操作键、目标。点「知道了，开始玩」进入游戏；游戏里再点 Start 开始 按钮才开始计时。
玩的时候按提示卡上的键操作。多数游戏考验把握时机（在正确的瞬间按键/点击）。
机会次数每个游戏最多 3 次。失败后点结算框上的「下一个游戏」进入下一局（同一款游戏最多 3 次）。
一局结束弹出结算框，请为这款游戏的 难度（1 易 / 2 中 / 3 难）和 趣味性（1 低 / 2 中 / 3 高）各选一个，然后点「下一个游戏」。
玩不动 / 玩不下去顶部有 「跳过本游戏」（记为跳过，不计入成功率）和 「暂停（保存）」。屏幕小可以用顶部的「缩放」调到 75%。
进度会自动保存：进度存在你自己的浏览器里。关掉页面、关掉电脑都没关系——下次用同一个浏览器打开同一地址， 点「继续上次评测」即可从断点接着做。
请固定用同一台电脑、同一个浏览器、同一个地址（换浏览器或换设备会看不到进度）。

四、做完之后（重要）

  1. 做完第 69 个游戏后，会自动跳到结果页。
  2. 点 「导出 CSV」，会下载一个文件，文件名形如 你的名字_评测结果.csv。
  3. 把这个 CSV 发回给发起人（微信 / 邮件 / 群里都行）。这是本次评测唯一需要交回的东西。

想中途看结果也可以：在评测页点「暂停（保存）」，或在入口页点「查看上次结果」。

五、常见问题

现象怎么办
macOS / Linux 提示 Permission denied解压工具可能没有保留可执行权限。在该文件夹里执行一次 chmod +x 启动评测-macOS-Linux.sh，然后重新运行即可。
双击 bat 后窗口一闪就没了说明本机 PowerShell 被安全策略限制。请改用：装 Python 3 后执行 python3 -m http.server 8765（在该文件夹里），再浏览器访问 http://localhost:8765/。
浏览器打开是空白 / 一直转圈看命令行窗口是否还开着；关掉了就重新双击启动脚本。地址必须是 http://localhost:端口/，不能是 file://。
提示端口被占用启动脚本会自动在 8765–8785 之间挑一个空闲端口，按窗口里打印的地址访问即可。
按键没反应① 先把输入法切英文；② 用鼠标点一下游戏画面让页面获得焦点；③ 别把窗口切到后台。
页面提示「请用本地 HTTP 打开」你打开的是 index.html 本身。请关掉它，改用启动脚本（见第二节）。
不小心关掉了页面重新用启动脚本打开，点「继续上次评测」，进度不会丢。
想重新从头做入口页有「放弃并重新开始」——注意这会把已有进度清掉，请谨慎。
关于数据：你玩的过程与成绩只保存在你自己的电脑上（浏览器本地存储），不会上传到任何服务器； 只有你最后主动导出的那个 CSV 会离开你的电脑。姓名可以填昵称或编号。
